The mode is multiplicative only when `ValueModelMode` equals `"multiplicative"` ([mode switch](https://github.com/xai-org/x-algorithm/blob/ed78e0645cfafcd026cfc1fd0da964f630533334/xai-value-model/weights.rs#L116-L125)); its public default is `"weighted"` in both parameter files ([Home Mixer](https://github.com/xai-org/x-algorithm/blob/ed78e0645cfafcd026cfc1fd0da964f630533334/home-mixer/params/param.rs#L602-L607) · [VM Ranker](https://github.com/xai-org/x-algorithm/blob/ed78e0645cfafcd026cfc1fd0da964f630533334/vm-ranker/params.rs#L151-L156)), and the exponent, offset and bias default to 0.0.
